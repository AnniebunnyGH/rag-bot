# Prana-Siphoning

**Aether-Prana vampirism** is a Sourcery Skill in Divinity: Original Sin II.

## Description
Drain target living character without Magic Armour to steal 1 Aether-Prana point from them. If used against a spirit they will cease to exist. If used on Shrieker they will perish.

## Location
### Traders
Due to the nature of this spell, it cannot be bought from any NPCs in the game.

### Main Questline and Exploration
; Gallow Shore
It becomes obtainable during the quest Powerful Awakening. Return to the The Liminal Necropolis once the second Aether-Prana point is unlocked.

; Isle of the Forgotten Pantheon
In case godwoken chose not to learn the skill from their god it is possible to learn it by reading Tools of the Archon-Ascendants: Prana-Siphoning within the Academy of the Seven on the Isle of the Forgotten Pantheon.

Prana-Siphoning is located on under Memorised Skills and is considered an 'Innate Skill'. Acquiring the skill will allow players to consume spirits during certain dialog choices, with the exception of those from Electrocuted/Charred corpses.

## Notes
* If this ability is used against spirits it will make that character unable to pass the Path of Blood and obtain Lucian's Blessing as they will be deemed impure.
